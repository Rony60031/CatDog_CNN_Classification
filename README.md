# Cat and Dog Image Classification Using CNN

A Deep Learning project for classifying cat and dog images using a Convolutional Neural Network (CNN) with PyTorch.

## Technologies
- Python
- PyTorch
- Torchvision
- NumPy
- Matplotlib

## Features
- Image preprocessing
- CNN architecture
- Training and validation
- Data augmentation
- Adam optimizer
- Learning rate scheduling
- Model evaluation
- Confusion matrix

## Experiments
1. Original CNN
2. Adam optimizer
3. Data augmentation
4. Optimized CNN

## Best Results
- Test Accuracy: 91.40%
- Selected Checkpoint: Epoch 17
- Lowest Validation Loss: 0.2115

## Main Files
- model.py
- train.py
- train_adam.py
- train_augmented.py
- train_optimized.py
- train_validation.py
- evaluate_optimized.py
